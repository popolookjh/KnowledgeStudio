# Knowledge Studio v0.1.0-tier1

The first public Tier 1 prerelease. This is a pre-1.0 project; the implementation
status and release limitations are documented below.

## Included

- Local Markdown vaults, CodeMirror editor, sanitized preview, wiki links/backlinks,
  metadata, tags, SQLite FTS5 search, graph, templates, canvas, and attachments.
- History, selected-file Git workflows, Persian/RTL support, and import/export.
- Stable vault/document IDs, provenance, durable change feed, Bases views/Kanban.
- Desktop HTML clipping, PDF annotations with cited export, read-only MCP Retrieval
  V2, and Zotero offline import/configured loopback integration.
- Plugin manifest discovery/permission policy and optional AI provider settings.

## Scope

This is a pre-1.0 release. Windows x64 is the packaging target; installers are
unsigned. Third-party plugin runtime execution is deferred. No bundled hosted AI
assistant, browser extension, cloud synchronization, mobile client, or collaboration
service is included. macOS/Linux release acceptance remains unverified.

## Source installation

Use Node.js 22.13 or newer and the package-manager version pinned in package.json.
Run corepack pnpm install --frozen-lockfile, corepack pnpm build, then
corepack pnpm --filter @knowledge-studio/desktop start.

License notices are included in the application package and release assets.
Verify downloads against the published SHA256SUMS.txt.

## Validation and dependency review

341 unit/integration tests and 15 Electron E2E tests (13 development plus 2 packaged)
passed on Windows x64. Lint, typecheck, formatting, build, MCP smoke, benchmarks,
staging/ASAR audits and unsigned installer generation were verified.

Development-tool security patches remove the detected high/critical advisories.
One moderate, build-only sprintf-js advisory remains without a published patch;
see [dependency security review](https://github.com/popolookjh/KnowledgeStudio/blob/main/docs/releases/dependency-security.md).
The production dependency audit reported zero advisories. This is not a guarantee
that the application or Electron/Chromium has no security flaws.

The release includes the unsigned Windows x64 installer, license notices, and
SHA-256 checksums. The installer was built and audited but was not installed.
